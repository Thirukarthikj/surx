# fuelplate-recipes-template — source code

Live demo: https://kedhar-components.pages.dev/#fuelplate-recipes-template

Folders under components/ are React + TypeScript + Tailwind components.
Main file: components/fuelplate-recipes-template/fuelplate-recipes-template.tsx  (usage example: components/fuelplate-recipes-template/demo.tsx)

Put each folder's .tsx file at src/components/ui/<folder>.tsx in a
shadcn-style project (the code imports siblings as @/components/ui/<name>).

npm packages used: gsap, react
